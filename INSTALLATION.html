🛠️ Installation Steps

Step 1: Download XAMPP

Download and install XAMPP from the official website:

Download XAMPP

Install XAMPP and start both Apache and MySQL services.

Step 2: Create Database

  1. Open your web browser and go to http://localhost/phpmyadmin
  2. Click "New" to create a new database
  3. Name it beauty_booking
  4. Click "Create"
  5. Select the new database and go to "Import" tab
  6. Choose the database_schema.sql file from this package
  7. Click "Go" to import the database structure

Step 3: Install Website Files

  1. Copy all files from this package to your XAMPP htdocs folder
  2. Default location: C:\xampp\htdocs\beauty_booking\ (Windows)
  3. Or: /Applications/XAMPP/htdocs/beauty_booking/ (Mac)
  4. Create an uploads folder inside your website directory
  5. Inside uploads, create a gallery folder

Step 4: Configure Database Connection

Open config.php and verify these settings:

$host = 'localhost'; $dbname = 'beauty_booking'; $username = 'root'; $password = ''; // Empty for XAMPP default

These default settings should work with XAMPP out of the box.

Step 5: Test Your Installation

  1. Open your web browser
  2. Go to http://localhost/beauty_booking/
  3. You should see the BeautyBook homepage
  4. Try registering a new account to test functionality
⚠️ Important: Make sure both Apache and MySQL are running in XAMPP before accessing the website.

🔧 Troubleshooting

Common Issues

  • Can't access website: Make sure Apache is running in XAMPP
  • Database errors: Check if MySQL is running and database exists
  • Upload issues: Ensure uploads/gallery/ folder exists with write permissions
  • Styling problems: Clear browser cache and check CSS file paths

🎨 Customization

You can customize your BeautyBook installation:

  • Colors & Branding: Edit css/styles.css
  • Logo: Replace logo images in the CSS file
  • Content: Modify text in PHP files
  • Features: Add new services or extend functionality
