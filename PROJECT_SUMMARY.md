## 🚀 Installation Process

1. **Download XAMPP** and start Apache + MySQL
2. **Create database** named `beauty_booking`
3. **Import** `database_schema.sql`
4. **Copy files** to XAMPP htdocs directory
5. **Access** `http://localhost/beauty_booking/`
